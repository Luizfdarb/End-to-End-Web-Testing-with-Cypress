📖 Capítulo 3 - Configuração Básica

Arquivos de teste: examples/todo-app.spec.js, integration-v2/todo-app.spec.js

Comandos Básicos:

cd chapter-03
npm install
npm run cypress:open
cd chapter-03
npm install
npm run cypress:run

Comandos Avançados (Disponíveis):

npm run cypress:chrome # Executa no Chrome
npm run cypress:firefox # Executa no Firefox
npm run cypress:tablet-view # Viewport de tablet
npm run cypress:electron:headed # Modo headed
npm run cypress:firefox:headless # Firefox headless
npm run cypress:chrome:headless # Chrome headless
✅ Recomendado para: Modo interativo (cypress:open) para aprender e debug

🌍 Cypress Real World App

Descrição: Aplicação completa para prática real com todas as funcionalidades

Passo 1: Instalar dependências

cd cypress-realworld-app
npm install

Passo 2: Iniciar a aplicação

npm run start

Passo 3: Executar testes

npm run cypress:open
npm run cypress:run

Comandos Específicos:

npm run test:api # Testes de API
npm run test:unit # Testes unitários
npm run cypress:open:mobile # Modo mobile
✅ Recomendado para: Prática completa e aprendizado avançado

🔄 Comandos para Todos os Capítulos

# Script para executar todos os capítulos
for /d %i in (chapter-*) do (
  cd %i
  npm install

)

📊 Comandos Úteis

cypress open --browser chrome # Abrir no Chrome
cypress open --browser firefox # Abrir no Firefox
cypress run --browser chrome # Executar no Chrome
cypress run --headed # Modo headed
cypress run --spec "path/to/spec" # Executar teste específico

🔧 Troubleshooting

Problema: Testes falhando por URL inválida
Solução: Atualizar URLs nos arquivos .spec.js para https://demo.playwright.dev/todomvc/
Problema: Dependências desatualizadas
Solução: Executar npm install em cada capítulo

📱 Modo Mobile

cypress open --config viewportWidth=375,viewportHeight=667
